# Noodle · DailyCong

Ten daily questions from the Noodle group chat.

This repository contains only the public browser game and its current reviewed quiz. Full chat archives, research databases, attachments, credentials and editorial working files are not included.

Scores and progress are saved in the player's browser. No account or server leaderboard. November 6, 2026 is round #1. Future game modes in the navigation are marked Coming soon.

The site asks search engines not to index it; this is not access control. This repository and its published game are public.
